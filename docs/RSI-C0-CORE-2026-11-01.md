The core issues exactly one request with a fixed development prompt. It accepts
only a strict JSON program/explanation envelope, interprets the numerical
program with the closed language, and grades actual loss and first-derivative
outputs at every declared point. All 23 points must conform before development
retention. The original textbook baseline is measured by the same grader.

Invalid output, transport timeout/error, evaluator error, changed inputs and
unobservable final inputs retain explicit failure states. There is no hidden
retry. Raw model text is bounded, and transport exception details are excluded
because they may contain sensitive connection information. Extremely inaccurate
but finite candidates can overflow a diagnostic float; that diagnostic becomes
null with an explicit range-error field, while the Decimal rejection and actual
outputs are retained. Failure records remain strict JSON.

was loaded or queried for this work package. Existing core qualification and
