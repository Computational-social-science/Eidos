## 网络实测与修改

系统通过 1Gbps 有线网卡出网，Wi-Fi 协商 29Mbps，但没有被选为默认出口。TCP receive-window autotuning=normal，RSS 全局启用。未修改 DNS、MTU、网卡驱动、TCP 算法、防火墙或安全软件。

对 GitHub、GitHub API、PyPI、npm、Hugging Face 与 Cloudflare 5MB 样本进行了两轮直连/本机代理对照：直连 12 次中 5 次完成，代理 12 次全部完成。直连 Hugging Face 2/2 被重置，PyPI 2/2 在 12 秒限制内未完成。5MB 样本直连约 0.298–0.326 MB/s（均未完成），代理约 2.25–2.98 MB/s（完成）。这是特定时段和端点的测量，不是运营商带宽或全互联网速度的承诺。

保存前状态后，设置用户级 HTTP_PROXY/HTTPS_PROXY 为现有的 http://127.0.0.1:7890，NO_PROXY 排除 localhost、loopback 与私网范围；为 GitHub Git HTTP 配置同一代理。保持官方包源与 TLS 验证，未采用随机镜像或第三方 GitHub 中转站。代理软件停用时，需要切回直连或清除这些环境变量。

从用户注册表加载新配置后复测 5 个端点：全部 HTTP 200。GitHub 1.46s，PyPI 1.31s，npm 0.83s，Hugging Face 0.71s；5MB 文件 2.68s（约1.87 MB/s）。这些请求同时有少量并发，不能当作独占链路峰值。

用户 PATH 去除重复项并补入 ~/.local/bin 与已存在的 Quarto bin；设置用户 QUARTO_BIN。现有 Codex/终端进程需要重开才继承用户级环境，本次启动的服务已显式配置。
