# Exact edit-rate acceptance

The repaired edit distances agree with the independently qualified reference for every supplied pair.

This is a retrospective complete-file check, not a population claim or scientific
novelty result. Execute the producer and independent validator before assessing
this claim. Missing results, source changes or data changes require revalidation.

The original HPAF README promises normalized Levenshtein distance, while its
engine computes a nonminimal opcode-script cost. The adapter separates the
quantitative metric from visual alignment. See CASE.md and the publication report
for methods, private/public replay boundaries, provenance and unfavorable results.
