# Installed numerical-program trials v0.4.11

Raw controlled measurements, not an autonomous-research or RSI certificate.
Windows and public-core-2 are the primary numerical API installations. sdk-core
adds offline SDK lifecycle, controlled Quarto and reproduction. Tracking and
recovery use an exact-ID, owned-container-installed candidate image; recovery is
source-checkout qualification of disposable services, not legacy migration.

The first public-core worker passed, but its controller conservatively failed
because generic Docker inspect used lowercase absence wording. The typed probe
addendum confirms later absence without changing that FAIL. build-tracking first
timed out during image commit; attempt2 passed. Earlier mutable-tag and misparsed
Dockerfile experiments are not qualification inputs. Historical receipts remain.

The 24 dependency wheels are not redistributed here: their sizes/hashes are in
bootstrap/bootstrap-manifest.json, URLs/hashes in bootstrap/uv.lock. The file
bootstrap/core-requirements.txt is
the frozen normal core closure. Public bootstrap and offline execution are
separate. The Eidos wheel is a separate public release artifact. No model weights,
credentials or paid-service calls are required.

Source snapshots use .snapshot so pytest cannot import archived copies. The
primary successful/timeout controller snapshots match their recorded raw hashes.
The first failed public-core controller source is not included; its unqualified
record and diagnostics are retained, not silently promoted.
