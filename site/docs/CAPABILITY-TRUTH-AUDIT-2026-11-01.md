## Important open defects and acceptance work

1. **Generic Docker/Binder delivery is incomplete.** The old generator references
   missing requirements and omits the installable project/lock/framework sources.
   Successful case ZIPs do not prove that path works. Repair a bounded manifest,
   explicit reproduction command and provenance, then execute a clean install/run.
   Until then this path must not be advertised as verified one-click execution.
2. **High-level research model integration is not qualified.** StageAwareScheduler
   is an inference-preparation library; registered experiments execute commands.
   A list of proposed model roles does not demonstrate an autonomous research
   lifecycle. Freeze task-specific blinded evaluations before selecting/promoting
   stronger reasoning/code candidates and linking them to scientific stages.
3. **Cross-project transfer remains insufficient.** Demonstrate an independently
   onboarded second problem with deliberately incorrect evidence and missing
   output, not only the Softmax mechanism and self-authored fixtures.
4. **Operational observation is not a clean soak.** The existing 24-hour record
   retains development/recovery failures. Current OK samples do not erase them.
   Restart and login recovery, uninterrupted availability and periodic observation
   are different acceptance claims.
5. **Formal/runtime and backend coverage is bounded.** Formal toolchain snapshot
   binding, AMP/bfloat16/higher-order gradients, unseen data/models and long-context
   model quality require their own controls and independent acceptance.

## Rule for further work

For every public promise, find its concrete caller, required inputs, actual output,
failure path and acceptance witness. A configuration flag, constructor, healthy
HTTP endpoint, fixture count or review document cannot substitute for the next
step. Missing execution remains UNRUN/UNQUALIFIED/BLOCKED as appropriate; expected
negative outcomes remain visible. Repair the actual path before broadening the
claim. Changes to already accepted evidence or criteria require explicit provenance,
not a rewrite that makes a new summary look green.
