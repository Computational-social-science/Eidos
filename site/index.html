Position¶

What it is, what it is not, and where knowledge lives.

It is a skeleton

One clone, many projects. bootstrap_project.sh produces a project wired to the same gates, the same provenance and the same rendering path. An existing repository is registered by pointer — never moved, never copied.

It is not a paper factory

Nothing here decides what is true. It decides what may leave the pipeline: a result is certified by gates, a claim by Gate S, and a judgement by a human gate when the operator's confidence is below threshold.

Knowledge has three homes

Procedure → agent skills. Facts → agent memory. History → the project's own LESSONS file. A framework vector store was built, never written to, and deleted; the lesson is recorded, the code is not.

Gates: two kinds, plus a validator¶

Two gate families, one validator, and a matrix that says where each one sits.

Dual gates

Quantitative — BootLoops protocols: acceptance thresholds with an explicit direction, planted truths, independence bookkeeping, timing discipline.

Semantic — Inspect, DeepEval, Promptfoo and Ragas for agent traces, RAG faithfulness and prompt regressions. A missing tool is a SKIP, named, never a pass.

Human — mandatory at hypothesis confirmation, experiment design and final submission. A gate nobody signs is a gate nobody owns.

Gate S — validation

Verification asks whether we built it correctly. Validation asks whether the claim is the one the evidence licenses. Gate S reads analysis/CLAIMS.yaml and refuses: a claim absent from the deliverable, an evidence pointer that no longer resolves, "supported" without preregistration and a negative control, an undeclared scope axis, an under-reported referee count, or a formal claim the Lean chain cannot reproduce.

The demo: Softmax Collapse & Cancellation¶

Published numerical fixes, independently checked and exposed through the existing Paper2Agent chain.

Two floating-point failure modes in published softmax and cross-entropy kernels. Softmax Collapse loses the dominant target gradient; Softmax Cancellation loses the difference between nearby distributions.

Collapse: preserve the small derivative

A max shift prevents exponent overflow; subtraction from 1 can still erase the target gradient. Exclude exactly one argmax before log1p; compute the target derivative as a negative sum of the non-target derivatives. Both forward and backward need the repair.

Cancellation: retain the logit difference

Subtracting rounded probabilities loses information near the teacher. Use teacher logits, centered logit differences and expm1/log1p, then enforce the zero-sum correction. Use the ordinary difference in the far branch; preserve exact equality.

Use the tested implementation · PyTorch, first-order float32/float64 
from framework.stable_numerics_torch import logit_distillation

loss = logit_distillation(student_logits, teacher_logits).mean()
loss.backward()
# For hard targets, use hard_cross_entropy(logits, targets).mean().

The source bundle contains the full implementation and independent tests. AMP, bfloat16 and higher-order derivatives require separate qualification.

Limits and licence¶

What this page will not claim.

What is measured. Tests, coverage, chain verdicts, Lean runs, decision calibration, and the demo's error against independent high-precision arithmetic.

What is not. That the gates improve a project's science — that would need a control group this programme does not have. That the interfaces generalise beyond three sealed fixtures. That a project's PDF path works everywhere: Quarto is installed outside the repository and reached through QUARTO_BIN, so a clone without that variable reports SKIP; TinyTeX is a separate install and its absence limits PDF rendering. Coverage is uneven; framework/inference is exercised mainly by chains.

Licence. The framework is MIT. The decision operator's weights are CC BY-NC 4.0 (non-commercial): a project that needs commercial terms must swap the operator, and the framework must not assume it is redistributable.
