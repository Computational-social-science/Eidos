01Position

What it is, what it is not, and where knowledge lives.

It is a skeleton

One clone, many projects. bootstrap_project.sh produces a project wired to the same gates, the same provenance and the same rendering path. An existing repository is registered by pointer — never moved, never copied.

It is not a paper factory

Nothing here decides what is true. It decides what may leave the pipeline: a result is certified by gates, a claim by Gate S, and a judgement by a human gate when the operator's confidence is below threshold.

Knowledge has three homes

Procedure → agent skills. Facts → agent memory. History → the project's own LESSONS file. A framework vector store was built, never written to, and deleted; the lesson is recorded, the code is not.

03Architecture

Delivery at the top, inference at the bottom. The gate layer is the only one that can stop a result from reaching the page.

04Gates: two kinds, plus a validator

Dual gates

Quantitative — BootLoops protocols: acceptance thresholds with an explicit direction, planted truths, independence bookkeeping, timing discipline.

Semantic — Inspect, DeepEval, Promptfoo and Ragas for agent traces, RAG faithfulness and prompt regressions. A missing tool is a SKIP, named, never a pass.

Human — mandatory at hypothesis confirmation, experiment design and final submission. A gate nobody signs is a gate nobody owns.

Gate S — validation

Verification asks whether we built it correctly. Validation asks whether the claim is the one the evidence licenses. Gate S reads analysis/CLAIMS.yaml and refuses: a claim absent from the deliverable, an evidence pointer that no longer resolves, “supported” without preregistration and a negative control, an undeclared scope axis, an under-reported referee count, or a formal claim the Lean chain cannot reproduce.

Decision layer, measured

A typed operator returns choice / yes-no / score with calibrated probabilities in one pass; prose stays with generators. Median 182 ms over HTTP for a two-question set.

Calibration, n=100. Accuracy 100.0%; abstention 0% vs 100% on answerable vs unanswerable items (Fisher p = 2.0e-29). The confidence floor is not identified (tau_identified = False; lowest confidence on a correct answer 0.54), so a gate may not use none_probability ≥ 0.2 as a success criterion. The option set does the work, not the threshold.

08Limits and licence

What is measured. Tests, coverage, chain verdicts, Lean runs, decision calibration, and the demo's error against a closed form.

What is not. That the gates improve a project's science — that would need a control group this programme does not have. That the interfaces generalise beyond two adopters. That a project's PDF path works here: Quarto is absent on this host. Coverage is uneven; framework/inference is exercised mainly by chains.

Licence. The framework is MIT. The decision operator's weights are CC BY-NC 4.0 (non-commercial): a project that needs commercial terms must swap the operator, and the framework must not assume it is redistributable.
