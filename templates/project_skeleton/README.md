# Project skeleton

Files here are copied into `projects/<name>/` by `bootstrap_project.sh`.

- `configs/project.example.yaml` — the annotated project configuration,
  including the explicit gate direction syntax. The bootstrap also writes a
  minimal `configs/project.yaml`; copy the example over it when you need the
  full set of options.
- `data/README.md` — the input contract for this project (what the pipeline
  reads, where it lives, how it is verified).

Nothing here is executable. The runnable scaffolding (scripts, Quarto config,
bibliography) is generated by the bootstrap so every project starts with the
same structure.
